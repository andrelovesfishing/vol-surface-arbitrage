# The reported metrics are fixed in the README before any data is analysed

The primary and secondary metrics, and what counts as a null result, are written
into the README before the analysis code runs.

## Consequences

The project cannot drift into reporting whichever cut of the data happened to
look most impressive, which is the standard failure mode of student quantitative
work and the first thing a sceptical reader assumes has happened. A null result
stays publishable: the pre-registration is what makes "we found almost nothing
tradeable" an honest finding rather than a failed project.
